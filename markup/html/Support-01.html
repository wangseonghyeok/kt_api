      안녕하세요

      API Link 플랫폼입니다.

      API Link 플랫폼(API GW SHUB) 전환 작업(2단계)과 관련하여 아래와 같이 일정 및 전환내용 공유드립니다.

      해당 기간 동안 전환 2단계 서비스 모니터링 및 이슈 확인에 적극적인 협조를 부탁드립니다.

      아래는 단계별 전환 일정입니다.

      가) PRD 서비스 전환 일정 (KT Cloud 에서 Azure Cloud 로 트래픽 Redirection)

      1차 : 2026.01.15 (목) 19:00 - SCAP ID

      2차 : 2026.01.20 (화) 19:00 - SCAP CUS

      3차 : 2026.01.22 (목) 19:00 - CAPRI

      나) PRD DNS(IP) 전환 일정 (22:00 ~ 23:00 사이 수동 작업)

      1차 : 2026.01.27 (화) 22:00 - cus-in.api.kt.com

      2차 : 2026.01.29 (목) 22:00 - cus.api.kt.com, anycus.api.kt.com

      다) 전환 시 유의 사항

      DNS 전환 작업 중 연동 오류 발생 시, 일부 서비스는 프로세스 재기동 또는 hosts 설정 변경 등 인프라 조치가 필요할 수 있습니다.

      전환 작업 시간대에 운영 작업 및 장애 대응이 가능하도록 사전 협조를 부탁드립니다.

      아래는 전환 작업(2단계) 상황실 정보입니다.

      연동 중인 대내·외 서비스 담당자, 운영자, 개발자 분들과의 원활한 소통을 위해 전환 상황실(카카오톡 오픈채팅방)을 운영하고자 합니다.

      가) 운영 목적

      전환 작업 진행 상황 실시간 공유

      서비스 이상 유무에 대한 신속한 확인 및 대응 지원

      나) 참여 안내

      아래 공유드린 오픈채팅방 링크를 통해 입장해 주시기 바랍니다.

      전환 기간 동안 서비스 모니터링 및 이슈 발생 여부를 확인해 주시면 감사하겠습니다.

      입장 시 서비스 확인을 위해 인증키에 등록된 "SCAP(홍길동)" 형식으로 이름을 변경해 주시기 바랍니다.

      (관통테스트 메일 제목내 서비스명 사용)

      다) 오픈채팅방 정보

      오픈 채팅방 주소: https://open.kakao.com/o/gxat6N2h

      오픈 채팅방 제목: API Link 플랫폼(API GW SHUB) 2단계

      오픈 채팅방 코드: a23456

      입장 시 프로필 네이밍 룰 : “서비스명(홍길동)“ 형식 ex. API Link SMS 발송(조명희)

      라) 2단계 API별 차수 및 서비스별 차수 파일 첨부

      감사합니다.
