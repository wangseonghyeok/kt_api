    • 첨부파일 API Link 사용가이드 패키지_251125- 배포용.zip

      안녕하세요. API Link 관리자입니다.

      API Link 포털에서 API Link 사용가이드 패키지를 활용하여 API Link GW API 사용 서비스를 신청할 수 있습니다.

      • 회원가입 권한 신청
      • API Link GW 서비스 등록하기(ID/PW 인증프로세스 또는 OAuth 인증프로세스)
      • 민감정보(IMSI, IMEI, ICCID) 보유 API 사용가이드 강화 가이드
      • Geo master 서비스 이용하기

      또한 API Self Testing Tool, Postman 사용가이드, 별첨 방화벽 정책 신청서도 제공합니다.

      감사합니다.
