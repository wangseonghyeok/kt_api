OAuth 앱 설정

KT 계정 연동에 필요한 OAuth 2.0 앱 정보를 설정하세요.

Redirect URI *

인증 완료 후 리디렉션할 URI입니다. 최대 5개까지 등록 가능합니다.

제공 정보 선택 (Scope) *

로그인 시 사용자에게 동의 요청할 정보 항목을 선택하세요.

  • KT OAuth 서비스는 Authorization Code 방식으로 고정 제공됩니다.
  • 선택한 모든 Scope는 워크스페이스 승인 시 함께 승인 처리됩니다.
