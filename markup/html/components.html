Popup

공통 팝업은 버튼의 data-popup-url로 대상 HTML을 불러오고, data-popup-fragment에 지정한 모달 영역만 화면에 표시합니다. 팝업이 열려 있는 동안 바깥 페이지 스크롤은 잠기고, 닫으면 기존 스크롤 위치로 돌아갑니다.

Auth Popup Loader

  • 열기data-popup-open에 공통 팝업 ID를 지정합니다.
  • 불러오기data-popup-url에 같은 경로의 HTML 파일명을 넣습니다.
  • 추출 영역data-popup-fragment로 실제 표시할 영역을 지정합니다.
<button type="button"
    data-popup-open="#componentAuthPopup"
    data-popup-url="login-01.html"
    data-popup-fragment=".kt-auth-modal">
    login 01
</button>

<div class="popup kt-popup-loader" id="componentAuthPopup" role="dialog" aria-modal="true" aria-hidden="true" aria-label="인증 공통 팝업" hidden>
    <div class="kt-popup-loader__content" data-popup-content tabindex="-1"></div>
</div>
