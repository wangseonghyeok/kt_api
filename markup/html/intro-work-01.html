API Workspace

KT REST API를 팀 단위로 구독·관리하고 멤버, API 구독, IP Whitelist, API Key를 하나의 워크스페이스에서 통합 관리하세요.

시작하기

API Workspace 생성부터 DEV Key 발급까지 단계별로 안내합니다.

  1. 1
    계정 준비

    로그인 방식에 따라 사전 준비사항이 다릅니다.

    KT 내부 Entra ID SSO 계정 준비 별도 가입 없이 KT 사내 계정으로 로그인 가능
    외부 파트너 LDAP 계정 필요 KT 담당 PO에게 계정 발급 요청 후 로그인
  2. 2
    워크스페이스 생성

    My Workspaces → Create Workspace에서 생성합니다.

    KT 내부 유형선택 기본정보 Members API선택 IP Whitelist 저장
    외부 파트너 유형선택 기본정보 Partner KT Service 선택 Members API선택 IP Whitelist 저장
  3. 3
    API 구독 신청

    워크스페이스 상세에서 + Add API를 클릭하여 필요한 API를 선택합니다.

    민감 파라미터 미포함 API 자동 승인 DEV Key 즉시 발급
    민감 파라미터 포함 API 사용 사유 입력 관리자 승인 대기 (Pending)
  4. 4
    DEV 환경 테스트

    발급된 DEV Key로 개발 환경에서 API를 호출하고 테스트합니다.

  5. 5
    PRD 전환 신청

    DEV 테스트 완료 후 상용 배포를 위해 PRD 전환을 신청합니다.

    KT 내부 Domain PO 승인 후 PRD Key 자동 발급
    외부 파트너 Partner KT Service PO 승인 후 PRD Key 자동 발급

핵심기능

  • API 구독 관리

    필요한 KT REST API를 검색하고 구독을 신청할 수 있으며, 민감 파라미터 포함 API는 관리자 승인 후 사용할 수 있습니다.

  • API Key 발급

    DEV/PRD 환경별 API Key가 자동 발급되며, 하나의 키로 구독한 모든 API에 접근할 수 있습니다.

  • IP Whitelist

    API 호출 서버의 IP를 환경별로 등록하며, KT 내부는 Private IP, 외부 파트너는 Public IP 등록이 가능합니다.

  • 팀 멤버 관리

    Owner, Manager, Member 역할별로 팀원을 초대하고 권한을 설정 및 관리할 수 있습니다.
